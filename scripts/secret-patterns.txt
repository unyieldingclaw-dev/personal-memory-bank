# Secret patterns for scripts/pmb-journal.{sh,ps1}. One extended regex per line; '#' starts a comment.
# Matched CASE-INSENSITIVELY by both twins (spec F20). Use only syntax that both `grep -E` and .NET
# regex accept: no POSIX [[:classes:]], no \s, no lookarounds. Both twins REFUSE the write when this
# file is missing, has no patterns, or holds a pattern that cannot be applied.
# Sources: the first five patterns come from scripts/pre-push-check.sh check_secret; the private-key
# pattern is added here, then the credential shapes most likely to be pasted in this environment:
# cloud, forge and chat tokens, JWTs, bearer headers and URL credentials. Best effort, not a complete
# secret scanner: a value in a shape not listed here is stored. A body is matched one LINE at a time,
# so a key on one line and its value on the next is stored too. Over-matching prose such as
# "the secret: importantstuff" is accepted, because a refusal costs one retry and a stored secret is
# plain text under .git/. The same goes for a path after `pwd:`, for `basic` followed by a long word,
# and for a bare `pass` assignment ("tests pass: everything green" is refused: 8 or more characters
# after the colon read as a value).
